# Доверие к конверсии

Локальный калькулятор: по числу заявок и факту конверсии строит **интервал Уилсона** — какие долгосрочные уровни ещё совместимы с этими данными.

Не отвечает «менеджер хороший / плохой». Отвечает, что ещё согласуется с выборкой, если заявки однотипны и уровень за период не менялся.

## Запуск

Откройте `index.html` в браузере. Сборки, сервера и зависимостей нет: один файл, HTML + CSS + JS.

## Что вводить

| Поле | Обязательно | Смысл |
|---|---|---|
| Заявки | да | Число наблюдений `n` (заявки, не менеджеры) |
| Факт, % | да | Конверсия в этой выборке. На `n` округляется до целого числа продаж `k` |
| Ожидаемая, % | нет | Среднее по направлению: типичный уровень, не мишень «попасть ровно» |
| Плановая, % | нет | Минимум компании: доля **не ниже** этого порога |
| Покрытие | да | 90 / 95 / 99% — свойство метода, не «вероятность 95% для этого человека» |
| Точность ±, п. п. | да (по умолчанию 5) | Размах, при котором оценку уже считают относительно узкой |

## Что смотреть в результате

1. **Полоса интервала** — совместимые уровни. Крайние 0% и 100% читайте по верхней / нижней границе, не как «± точность».
2. **Ожидаемая внутри полосы** — типичный уровень ещё может объяснять факт. Снаружи — «аномалия» (плохо совместим). Хвост бинома только поясняет, как редко такое бывает при ожидаемой.
3. **Плановая** — порог «не ниже». Зелёный, когда вся полоса уже выше минимума; красный — когда даже верх ниже плановой; иначе рано решать.

Справочник «когда данных хватает» — про **ширину оценки**, не про вердикт.

## Чего калькулятор не делает

- Не каузальный вывод и не оценка качества человека.
- Не правило остановки: не пересчитывайте каждую неделю до первой «аномалии».
- Не массовый скрининг команды одним порогом (у 20 человек «аномалия» появится и при норме).
- Не вердикт по ожидаемой с малой выборки: ожидаемую (среднее направления) считайте заданной. Если она сама с малой выборки — не используйте «аномалию» как вердикт.
